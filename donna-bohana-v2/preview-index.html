Builder Notes

What's in This Build

Globals + Tokens

  • Sage primary #7A9F4E, lavender accent #9B8BB4, amber tertiary used sparingly
  • Ocean charcoal #2C3A3F replaces pure black across all dark sections
  • Sand neutrals on body backgrounds, no pure white
  • Body 17px / 1.75 line-height; H1 clamp(40, 5.5vw, 66); buttons 13px / 0.12em / 2px radius
  • Header scroll background uses ocean charcoal with backdrop blur

SEO Setup (Rank Math)

  • Each indexable page has a focus keyword in the H1 plus at least one H2
  • Per-page meta titles, descriptions, and permalinks defined in rank-math-seo.md
  • Geographic distribution rebalanced across Malibu, Westlake Village, Lake Sherwood, Pacific Palisades, Coastal California (no pigeonhole)
  • Legal pages set to noindex, follow

Pattern Highlights

  • Buy + Sell pages: alternating large-image and text rows for the 6-step process
  • Home Valuation: instant-widget shortcode placeholder, Solstice process flow, detailed CMA form
  • Every bottom CTA is a parallax image with ocean-charcoal overlay
  • All hardcoded blacks swapped to ink-tinted rgba(47, 59, 51, x) shadows
