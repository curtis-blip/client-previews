How to Read This Document

Every rule below is rendered using the actual fonts, colors, and sizes the site should use. What you see on this page is what the live site should look like at the component level. No need to translate hex codes or font-size values into mental pictures, the doc shows it.

If something doesn't match the mockups: the mockups are the source of truth. The mockups consumed this same design system, so a mismatch means either the mockup needs fixing or this doc needs regeneration. Either way, surface it to Curtis before building.

This is the standard body copy style. It runs at a generous line-height because most blocks carry meaningful paragraph content (about teasers, agent bio, FAQ answers, community descriptions). Width caps around 65 characters per line for readability.
Typography Hard Rules
  • Heading and body font families MUST be loaded via Google Fonts link at top of every page.
  • Never substitute a system font fallback as the primary face: only as the secondary in font-stack.
  • Never introduce a THIRD font family for "accent" or "display": heading + body only.
  • No italic-serif accent spans inside H1s ("real estate, reimagined" is banned).
  • No em dashes anywhere in copy: replace with comma, period, colon, or middle dot.

Color Hard Rules

Spacing Hard Rules
  • Always use scale values: never one-off pixel or rem values.
  • Section padding-Y is generous by design (LP doctrine). Don't tighten it without explicit direction.

Buttons

Primary buttons use accent color. Secondary buttons are ghost (transparent with border). Both UPPERCASE with 0.08em letter-spacing.

Browse Listings
Accent

Button Hard Rules
  • Border-radius: 0. Sharp geometry only. No rounded buttons.
  • Never use 3+ buttons in a single hero. One primary, optionally one secondary, never three.
  • Transition duration 900ms with easing cubic-bezier(.2, .7, .1, 1) on hover.
  • Always include `:focus-visible` indicator (browser default OK, or styled with accent outline).

Motion

Slow, subtle motion. LP-style register. Never bouncy. Never fast.

TokenValueUse
--motion-duration-fast400msLink underline color changes, small UI feedback
--motion-duration-default900msButton hover, accordion expand
--motion-duration-slow1200ms to 1400ms (photo zoom on hover)Section fade-in, photo zoom on hover
--motion-easing-defaultcubic-bezier(.2, .7, .1, 1)All hover transitions
Motion Hard Rules
  • No bounce easing. No springs. No spinning loaders inside content.
  • Photo hover zoom maxes at 1.03 (3%). More feels gimmicky.
  • Respect `prefers-reduced-motion`: disable photo-zoom and section fade-in when set.

Voice and Content Reminders

Content writers and designers both need to remember these voice rules. Even if it's the writer's job, a designer who notices an em dash or "your trusted partner" should flag it before publish.

Copy Hard Rules
  • Never use em dashes (the long dash or `--`): replace with comma, period, colon, or middle dot.
  • Never use generic AI phrases: "dream home", "seamless experience", "every step of the way", "your trusted partner", "in today's market", "with confidence".
  • Never use generic city descriptors: "thriving", "vibrant", "nestled", "perfect blend", "world-class", "rich history", "something for everyone".
  • Never use parallel triplets ("Clear, calm, confident"), hyphenated compound metaphors ("courtroom-trained eye"), or conditional buildups ("Whether you're A, B, or C...").
  • Every page H1 references at least ONE specific item from the client's brief (years, credentials, niche, personal story).

Full doctrine: references/copy-voice.md in the Optimus Prime plugin.

Anti-Patterns Summary

The shortlist of "do not do this." Every rule below was learned the hard way on past builds.

Never Do These
  • Em dashes anywhere in copy
  • Emojis as icons (inline SVG only)
  • Rounded corners on cards, buttons, images
  • Carousel sliders in heroes
  • Italic-serif "register lift" spans inside H1
  • 3+ CTAs in a hero (1 default, 2 max)
  • Split heroes anywhere except a clean home-page exception
  • Two dark-background sections in a row
  • Aggressive form or large CTA inside the hero (exception: Home Valuation page widget)
  • Gradient placeholders past first draft
  • Raw shortcode embeds without styled container
  • Flat text-only service boxes (must have SVG icons)
  • Zigzag timeline layouts for process steps (use alternating image+text rows)
  • "Recently Sold Nearby" on Home Valuation page
  • 4-step process blocks shipped as production (always default to 8)
  • FAQ mode: faq on About page (use mode: expertise: Areas of Expertise)
  • Communities home-page treatment on inner pages (V2 home-only)
  • About teaser block on /about (always use full Agent Bio)
